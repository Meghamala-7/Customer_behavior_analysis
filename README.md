# 🛍️ Customer Behaviour & Sales Analysis

## 📌 Project Overview

This project analyzes customer shopping behaviour and sales data to understand purchasing patterns, customer segments, product performance, discount usage, subscription behaviour, and revenue trends.

The project follows a complete data analytics workflow, starting from raw data cleaning and preprocessing using **Python and Pandas**, followed by **SQL analysis** and an **interactive Power BI dashboard** to communicate the findings.

---

## 🎯 Project Objectives

- Clean and prepare the raw customer shopping dataset.
- Handle missing values and data inconsistencies.
- Transform the data into an analysis-ready format.
- Analyze customer behaviour using SQL.
- Identify revenue and sales patterns.
- Analyze product ratings and discount usage.
- Compare customer spending based on subscription status.
- Analyze shipping methods and purchasing behaviour.
- Segment customers based on previous purchases.
- Analyze revenue across different age groups and categories.
- Create an interactive Power BI dashboard.
- Generate business insights from the analysis.

## 📂 Dataset

The dataset contains customer shopping behaviour information.

### Key columns include:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases

The dataset contains **3,900 customer records**.
